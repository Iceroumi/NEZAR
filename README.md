# Nezar  — расширение для VS Code

**Nezar**  — это расширение для Visual Studio Code, которое помогает разработчикам быстро собирать весь код проекта в один файл для передачи в AI-инструменты, а также предоставляет другие полезные функции для работы с проектом.

## ✨ Возможности

- 📁 **Сбор всех файлов в один** — объединяет все исходные файлы проекта в один текстовый файл `merged-code.txt`.
- ⚡ **Сбор без пробелов** — создаёт минифицированную версию объединённого кода `merged-mini.txt`.
- 📄 **Копировать текущий файл** — копирует содержимое активного редактора в буфер обмена.
- 🌳 **Дерево проекта** — генерирует текстовое представление структуры папок и файлов `tree-list.txt`.
- 📋 **Боковая панель** — добавляет в Activity Bar панель RCP с кнопками быстрого копирования результатов в буфер обмена.

## 📦 Установка

### Из VSIX-файла
1. Скачайте `.vsix` файл расширения.
2. В VS Code откройте **Расширения** → нажмите `...` → **Установить из VSIX...**.
3. Выберите скачанный файл.

### Из исходников
1. Клонируйте репозиторий:
   ```bash
   git clone <url-репозитория>
   cd nezar
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Соберите расширение:
   ```bash
   npm run compile
   ```
4. Нажмите `F5` в VS Code для запуска режима отладки расширения.

## 🚀 Использование

### Команды
Все команды доступны через палитру команд (`Ctrl+Shift+P` или `Cmd+Shift+P`) с префиксом `RCP:`

| Команда | Описание |
|---------|----------|
| `RCP: Собрать все файлы в один` | Собирает все файлы кода в `RCP_AI/merged-code.txt` |
| `RCP: Собрать все файлы в один без пробелов` | Создаёт минифицированный файл `RCP_AI/merged-mini.txt` |
| `RCP: Копировать текущий файл` | Копирует содержимое активного файла в буфер обмена |
| `RCP: Дерево проекта` | Сохраняет структуру проекта в `RCP_AI/tree-list.txt` |

### Боковая панель
В Activity Bar появляется иконка **RCP**. В разделе **«быстрые функции»** доступны кнопки:
- 📁 Собрать все файлы в один (копирует результат в буфер)
- ⚡ Собрать все файлы без пробелов (копирует результат в буфер)
- 📄 Копировать текущий файл
- 🌳 Дерево проекта (копирует результат в буфер)

Все результаты копируются в буфер обмена без создания файлов.

## 📂 Выходные файлы

Все результаты сохраняются в папку `RCP_AI` в корне рабочей области:

- `merged-code.txt` — объединённый код всех файлов с заголовками.
- `merged-mini.txt` — минифицированный объединённый код.
- `tree-list.txt` — текстовое дерево проекта.

## ⚙️ Поддерживаемые файлы

Расширение обрабатывает файлы со следующими расширениями:

`ts`, `js`, `tsx`, `jsx`, `html`, `css`, `scss`, `less`, `json`, `py`, `java`, `cpp`, `c`, `h`, `cs`, `go`, `rs`, `rb`, `php`, `sql`, `sh`, `bash`, `yml`, `yaml`, `xml`, `md`, `txt`, `vue`, `svelte`.

**Игнорируются:**
- папки: `node_modules`, `.git`, `dist`, `build`, `.vscode`, `out`, `bin`, `obj`;
- файлы и папки, начинающиеся с точки.

## 🛠 Разработка

### Требования
- Node.js 18+
- VS Code 1.85+

### Скрипты
- `npm install` — установка зависимостей.
- `npm run compile` — сборка расширения.
- `npm run watch` — сборка с отслеживанием изменений.
- `npm run package` — production-сборка.
- `npm run lint` — проверка кода линтером.
- `npm test` — запуск тестов.

### Отладка
1. Откройте проект в VS Code.
2. Нажмите `F5` — откроется новое окно с загруженным расширением.
3. Используйте палитру команд для вызова функций.
