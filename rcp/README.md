# NEZAR – сбор всех файлов проекта в один документ

**NEZAR** — это расширение для VS Code, которое автоматически собирает все текстовые файлы вашего проекта (код, разметку, конфиги) в единый документ. Идеально подходит для:
- отправки контекста в AI-чат (DeepSeek, Алиса);
- быстрого поиска по всему проекту через один файл;


## 🚀 Возможности

- **Объединение всех файлов** – собирает все файлы с поддерживаемыми расширениями (см. список ниже) в один текстовый файл с разделителями.
- **Минифицированный сбор** – убирает пробелы и переносы строк, оставляя только содержание (уменьшает размер для отправки).
- **Копирование текущего файла** – моментально копирует содержимое активного редактора в буфер обмена.
- **Дерево проекта** – генерирует структуру папок и файлов в виде дерева (с учётом исключённых директорий).
- **Боковая панель** – все основные действия доступны в один клик через иконку в Activity Bar.


## 🔧 Использование

### Команды (палитра Ctrl+Shift+P)

| Команда | Результат |
|---------|-----------|
| `Nezar: Собрать все файлы в один` | Создаёт `NEZAR_AI/merged-code.txt` – объединённый код всех файлов. |
| `Nezar: Собрать все файлы без пробелов (минификация)` | Создаёт `NEZAR_AI/merged-mini.txt` – минифицированную версию. |
| `Nezar: Копировать текущий файл` | Копирует содержимое активного файла в буфер. |
| `Nezar: Дерево проекта` | Создаёт `NEZAR_AI/tree-list.txt` с деревом каталогов. |

### Боковая панель

Кликните на иконку **NEZAR** в левой панели (Activity Bar). Появятся кнопки:
- **📁 Собрать все файлы в один** – то же, что и команда.
- **⚡ Собрать все файлы без пробелов** – минифицированный сбор.
- **📄 Копировать текущий файл** – копирование активного файла.
- **🌳 Дерево проекта** – структура папок.

Все результаты **сразу копируются в буфер обмена** для быстрой вставки куда угодно.

## ⚙️ Поддерживаемые расширения и исключения

По умолчанию обрабатываются следующие расширения:  
`ts, js, tsx, jsx, html, css, scss, less, json, py, java, cpp, c, h, cs, go, rs, rb, php, sql, sh, bash, yml, yaml, xml, md, txt, vue, svelte`.

Папки, которые **игнорируются**:  
`node_modules, .git, dist, NEZAR_AI, build, .vscode, out, bin, obj`.

При необходимости вы можете изменить эти списки, отредактировав массивы `codeExtensions` и `skipDirs` в `src/extension.ts`.

## 📂 Выходные файлы

Все сгенерированные файлы сохраняются в папку **`NEZAR_AI`** в корне вашего проекта:
- `merged-code.txt` – полный код с заголовками файлов.
- `merged-mini.txt` – код без лишних пробелов и переносов.
- `tree-list.txt` – структура проекта.
